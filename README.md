# Документация СМИБ
Учебный объект: организация с почтой, персональными данными и финансовыми документами.
Изменения: отдельная ветка → запрос на слияние → замечание другого студента → исправление → одобрение → слияние → тег. Прямая запись в main запрещена после настройки облачной защиты. Секреты и реальные персональные данные не размещать.
